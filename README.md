# springpractice
# **Problem Statement**

Managing investments across multiple investors, funds, and portfolios is complex and requires efficient tracking.

* Companies receive funds from multiple investors and allocate them across different asset types.
* Employees managing portfolios need a centralized way to track investments and portfolio details.
* Manual tracking makes it difficult to monitor fund utilization, investment performance, and portfolio status.

**Challenge:**
To create a system that simplifies portfolio management and provides better visibility into investments.
# **Project Objectives**

* Develop a centralized platform to manage investor funds, portfolios, and investments.
* Enable employees to efficiently manage multiple assigned portfolios.
* Provide easy tracking of fund allocation, investment details, and portfolio performance.
* Simplify investment management through organized portfolio data and analytics.
